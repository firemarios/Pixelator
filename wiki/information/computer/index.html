Computer

The Computer is used to access cameras that are connected to a Server and have the video cable installed.

Gameplay

To use the computer, place it on a Server and right-click it to open the interface. From there, you can select a camera from the list of connected cameras. Once selected, you will be able to view the camera's feed in real-time.

Make sure that the camera is connected to the Server for it to function properly.

The computer can be used for various purposes, such as monitoring different areas, security surveillance, or simply observing your creations from a different perspective.

Press I on your keyboard to open the configuration menu when viewing a camera. There you can see which modules are installed. If for any reason the modules you have installed don't show just right click on them. You can toggle each module to on or off and they have fucntions such as night vision.
