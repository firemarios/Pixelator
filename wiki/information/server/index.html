Server

The Server creates a private network of cameras accessible only by the owner or by putting other player's id cards in the allow list.

Gameplay

To use the Server, you need to place it on the ground and right-click it. This will open a GUI where you can configure it.

In the GUI, you can see the amount of cameras connected to your server. You can add cameras by right-clicking the cable to the server and then right-clicking the camera.

You can also manage the allow list, which determines who can access your server. By default, only the owner can access it. To add other players, you need to put their id cards in the allow list.

For the server to store data you need to add a USB

Once you have set up your server, you can access it from any screen or Tablet using the search button.
